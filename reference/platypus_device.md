# Where the work will happen

Reports the PyTorch build in use and the device it can see. Starts the
engine if it is not running.

## Usage

``` r
platypus_device()
```

## Value

A list, printed readably.

## Why this page shows no output

What this prints is a property of the machine it runs on, so an example
output here would describe whichever machine built this page rather than
yours. Run it and read your own.

## Examples

``` r
if (FALSE) { # \dontrun{
platypus_device()
} # }
```
